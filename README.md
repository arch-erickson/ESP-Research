# ESP Research: Generating Facades

Research presentation for ESP / Tectonic Architecture (ARCH 3551, Sustainability History & Practice, CUNY, Fall 2026) by Cindi Sosa and Erickson Cabrera.

The whole deck is one self-contained file, `index.html`, published with GitHub Pages. Open it in Chrome or Edge, press **Present** for full screen and use the arrow keys. The 3D diagrams run live in the browser.
